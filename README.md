# qBittorrent Remote

A standalone, cross-platform Qt desktop application for remotely
controlling qBittorrent instances through the Web API.

## Development

The application is being developed independently, with selective
reuse of GUI components from the official qBittorrent project.

The `upstream-source` branch preserves the original qBittorrent
source code and history.
